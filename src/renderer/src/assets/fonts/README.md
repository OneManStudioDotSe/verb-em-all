# Bundled fonts

Self-hosted so the app renders identically offline and never contacts Google Fonts.

| File | Family | Axis | License |
|---|---|---|---|
| `SpaceGrotesk-latin.woff2` | Space Grotesk (variable) | wght 300–700 | SIL Open Font License 1.1 |
| `JetBrainsMono-latin.woff2` | JetBrains Mono (variable) | wght 100–800 | SIL Open Font License 1.1 |

Both are the latin subsets served by Google Fonts. Upstream: https://github.com/floriankarsten/space-grotesk and https://github.com/JetBrains/JetBrainsMono.
